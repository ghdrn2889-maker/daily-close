# 당일 마감

수익 · 경비 · 소비 · 고정지출 네 축으로 하루를 마감하는 개인 현금흐름 앱.

서버 없이 브라우저 안에서만 동작하며, 기록은 사용하는 기기의 브라우저 저장소에 남습니다.
이 저장소에는 앱 코드만 있고 개인 기록은 들어 있지 않습니다.

## 네 축

| 종류 | 뜻 |
|---|---|
| 수익 | 벌어들인 돈 |
| 경비 | 벌기 위해 쓴 돈 |
| 소비 | 나를 위해 쓴 돈 |
| 고정지출 | 매달 자동으로 나가는 구독 |
| 저축 | 쓴 게 아니라 옮겨 둔 돈 |

경비와 소비를 가르는 기준은 하나입니다 — **이 지출이 없었으면 수익이 줄어드는가.**

저축은 잃은 돈은 아니지만 **지금 쓸 수 있는 돈도 아닙니다.** 손닿지 않는 곳으로
옮겨간 것이므로 남은 돈에서 뺍니다 — 순익 = 수익 − 경비 − 소비 − 고정지출 − 저축.
대신 얼마나 모았는지는 따로 셉니다. 이번 달 탭의 **모은 돈** 칸이 누적과 월평균을 보여주고,
브리핑에도 그 달 저축액과 누적이 함께 나옵니다.

### 모으는 곳

같은 저축이라도 성격이 다릅니다. 적금은 약속한 기간과 회차가 있고, 따로 빼두는 돈은
목표만 있거나 그것도 없습니다. 한 칸에 넣으면 "이번 달 적금을 넣었나" 를 영영 알 수 없습니다.

| 종류 | 적는 것 | 따라가는 것 |
|---|---|---|
| 금융상품 | 한 달 납부액 · 기간 · 시작 월 | 넣은 회차, 남은 회차, 마지막 납입월, 진행률 |
| 자유 저축 | 목표 금액 (선택) | 모은 금액, 목표까지 남은 금액 |

저축을 기록할 때 저축처를 고르면 그쪽으로 쌓입니다(`txn.pot`). 안 고른 기록은 **지정 안 함**
으로 따로 묶입니다. 저축처를 지워도 넣은 기록은 지우지 않고 연결만 끊습니다.

금융상품은 이번 달 납입이 아직이면 브리핑이 알려줍니다 — 적금은 거르면 손해가 나므로.

예금을 깨서 돌아온 돈도 같은 이유로 수익이 아닙니다. 가져오기에서 자동으로 제외되며,
그때 넣어 둔 저축 기록을 지우는 것이 맞는 처리입니다.

## 파일

| 경로 | 용도 |
|---|---|
| `prototype.html` | **원본.** 아티팩트용 body 조각 (doctype 없음) |
| `당일마감.html` | 단독 실행본. 더블클릭하면 브라우저에서 바로 열림 |
| `docs/` | 배포본. GitHub Pages가 이 폴더를 서비스 |
| `build-standalone.js` | 원본에서 위 두 배포본을 생성 |
| `gen-icons.js` | 앱 아이콘 PNG 생성 (크롬으로 렌더) |

## 빌드

```bash
node build-standalone.js     # 당일마감.html + docs/index.html 갱신
node gen-icons.js            # 아이콘 다시 생성 (필요할 때만)
```

`prototype.html` 만 고치고 빌드하면 나머지가 따라옵니다. `docs/sw.js` 의 캐시 버전도
앱 버전을 자동으로 따라가므로, 배포하면 이전 캐시가 정리됩니다.

## 데이터

기록은 `localStorage` 의 `daily-close-v3` 키에 저장됩니다.
**주소마다 저장소가 별개입니다** — 배포 주소, 로컬 파일, 아티팩트는 서로 데이터를 공유하지 않습니다.

백업은 설정 → 데이터 → 내보내기에서 JSON 파일로 받습니다. 형식은 고정되어 있습니다.

```json
{ "app": "daily-close", "schema": 1, "exportedAt": "...", "data": { "txns": [], "presets": [], "recurrings": [], "cats": {} } }
```

가져오기는 이미 있는 기록을 건드리지 않고 없는 것만 추가하므로, 같은 파일을 여러 번 넣어도 중복되지 않습니다.

## 캐디 앱 연동

읽기 전용 창구 하나만 봅니다. 계약은 세 필드가 전부입니다.

```
GET /api/work-income?from=YYYY-MM-DD&to=YYYY-MM-DD
Authorization: Bearer <열쇠>
-> [{ "date": "2026-08-21", "count": 1, "amount": 170000 }, ...]
```

날짜별 합산이고, 0원인 날은 오지 않습니다. 이 앱은 쓰기를 하지 않습니다.

**열쇠는 저장소에 넣지 않습니다.** 사용자가 캐디 앱에서 발급해 화면에서 붙여넣고,
`state` 와 분리된 `caddieKey` 항목에만 둡니다. 그래서 백업 JSON 에도 실리지 않습니다.

동기화는 앱을 열 때 조용히 한 번(1시간 간격), 그리고 설정에서 수동으로 돌립니다.
받아온 구간은 그대로 맞춥니다 — 새 날짜는 추가, 바뀐 날은 갱신, 취소된 날은 삭제.
`ext:'caddie'` 표시가 없는 기록(직접 입력)은 절대 건드리지 않습니다.

### 서버 주소는 앱에서 바꿉니다

기본 주소는 코드에 있지만, 설정 → 캐디 앱 연동 → **서버 주소 · 바꾸기** 로 덮어쓸 수 있습니다.
`https://` 만 받고, 값은 `caddieApi` 항목에 열쇠와 마찬가지로 `state` 와 분리해 둡니다.
비워서 저장하면 기본 주소로 돌아갑니다.

주소가 바뀌는 이유는 하나입니다 — **브라우저는 공개 사이트가 사설망 주소로 요청하는 것을 막습니다.**
`*.ts.net` 은 A 레코드가 `100.x` (CGNAT 사설 대역) 라서 크롬이
`ERR_BLOCKED_BY_LOCAL_NETWORK_ACCESS_CHECKS` 로 차단합니다. 앱 쪽에서 우회할 방법은 없고,
캐디 앱이 공인 IP로 해석되는 주소를 내주어야 합니다. 그 주소를 받으면 여기에 붙여넣으면 됩니다.
